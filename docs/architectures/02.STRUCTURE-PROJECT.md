## Where routes live

- `/auth/*`, `/api/v1/profile*`, `/api/v1/accounts/{id}` and `/update_active_at`: `src/main.rs` → `auth.rs`.
- `/api/v1/accounts/{id}/...`: each module's `routes()`, merged in `account_routes()`. Unmatched paths answer
  `501 {"error":"Not implemented in Pulsar"}` and log `unported endpoint`.
- `/api/v2/accounts/{id}/...`: `reports::routes()`.
- `/api/v1/widget/*` and `/widget`: `widget::routes()` (no user auth, visitor token instead).
- `/rails/active_storage/*`: `storage::routes()`.
- `/cable`: websocket. `/app/*`: built frontend with `index.html` fallback. `/sdk.js`: embed loader.

## Environment

| Variable          | Default                       | Purpose                                         |
| ----------------- | ----------------------------- | ----------------------------------------------- |
| `DATABASE_URL`    | `postgres://localhost/pulsar` | Postgres connection                             |
| `BIND`            | `0.0.0.0:3000`                | Listen address                                  |
| `WEB_DIR`         | `web/build/client`            | Built frontend                                  |
| `STORAGE_DIR`     | `./storage`                   | Uploaded files                                  |
| `SECRET_KEY_BASE` | dev value                     | Signs file URLs and widget tokens. Required in production |
| `FRONTEND_URL`    | `http://localhost:3000`       | Public base URL, used in widget embed snippets  |
| `RUST_LOG`        | `info`                        | Log level                                       |
